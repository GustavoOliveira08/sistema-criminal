# sistema-criminal
Um sistema pensado para área de psicologia criminal. Criamos para a IPFAC (instituição fictícia), nasceu como um órgão interministerial de excelência. Seu objetivo inicial era unificar o cadastro de laudos comportamentais, traçar perfis psicológicos e auxiliar forças policiais e o sistema Judiciário na tomada de decisões estratégicas.
